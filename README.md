# AI安家帮 微信小程序

## 项目概况

完整的微信小程序项目，将 Web 版 AI安家帮 迁移到小程序，提供流畅的移动端体验。

## 核心优势

- **不需要 ICP备案** — 小程序天然可用，不受域名备案限制
- **原生级流畅体验** — 比 Web 页面在手机上快得多
- **微信生态集成** — 支持微信登录、支付通知、模板消息等
- **下拉刷新/上滑加载** — 原生 UI 交互

## 项目结构

```
anjiabang-miniapp/
├── app.js / app.json / app.wxss    # 项目入口和配置
├── project.config.json             # 开发者工具配置
├── utils/
│   └── api.js                      # API 请求封装（自动带 token）
├── pages/
│   ├── login/          # 登录/注册
│   ├── dashboard/      # 首页看板（统计、提醒、快捷入口）
│   ├── properties/     # 房源列表
│   ├── property-detail/# 房源新增/编辑
│   ├── tenants/        # 租客列表
│   ├── bills/          # 收租记账（含统计汇总）
│   ├── repairs/        # 维修报修
│   ├── filing/         # 合同备案（框架）
│   ├── customers/      # 客户管理（框架）
│   ├── utilities/      # 水电煤（框架）
│   └── settings/       # 个人中心/退出
```

## 页面功能清单

| 页面 | 功能 |
|---|---|
| 登录/注册 | 手机号+密码登录/注册，API 对接 |
| 首页看板 | 统计卡片(房源数/出租/空置/收入)、待办提醒、快捷入口、最近房源 |
| 房源列表 | 搜索、列表、下拉刷新 |
| 房源详情 | 新增/编辑房源信息、删除 |
| 租客列表 | 搜索、列表、删除、下拉刷新 |
| 收租记账 | 统计汇总(总收入/已收/待收)、标记已收、删除 |
| 维修报修 | 列表、标记完成 |
| 个人中心 | 用户信息、功能入口、退出登录 |

## 使用说明

### 1. 导入微信开发者工具

1. 打开微信开发者工具 → 小程序项目
2. 项目目录选择 `anjiabang-miniapp/`
3. 填入你的 AppID（没有的话用测试号也可以）
4. 点击导入

### 2. 修改 API 地址

打开 `utils/api.js`，将 `apiBase` 改为你的服务器地址：
```js
apiBase: 'https://你的域名/api/fang'
```

> 小程序开发环境支持"不校验合法域名"，可以在开发者工具里勾上

### 3. 开发模式调试

在开发者工具右上角点击"详情" → 勾选"不校验合法域名、web-view（业务域名）"
这样开发时 API 请求不会被拦截。

### 4. 后续完善方向

- 水电煤、合同备案、客户管理页面功能填充
- 微信一键登录（代替手机号密码）
- 微信支付收款通知
- 图片上传（房源照片、维修凭证）
- 模板消息推送（催租、合同到期提醒）
